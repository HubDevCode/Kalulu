## Kalulu 2.5.2

### New: Kalulu for Windows

Kalulu now runs on Windows 10 and 11 (64-bit). Download `Kalulu-v2.5.2-x64-setup.exe` and run it: the installer sets up everything Kalulu needs, with nothing else to install.

- **Everything included:** Kalulu, its audio codecs, `yt-dlp` for YouTube and YouTube Music, and `ffmpeg` and `ffprobe` for Opus, AAC and streams. Every download is checked against the checksums of its release while the installer is built.
- **No administrator rights:** it installs for the current user by default, and can install for all users.
- **Start menu** entry, optional desktop icon, uninstaller in the Windows settings, English and Italian.
- **yt-dlp stays current:** the bundled yt-dlp updates itself once a day, so YouTube keeps working.
- **Updates from the app:** Settings → Updates downloads the new installer, verifies it against `SHA256SUMS`, installs it and starts Kalulu again.
- **No console windows:** yt-dlp, ffmpeg and the other helpers run hidden.

The installer is not signed, so Windows SmartScreen may warn about it: choose **More info → Run anyway**.

### Linux

- The AppImage is built as before. Kalulu now also starts when the single-instance socket cannot be opened.
